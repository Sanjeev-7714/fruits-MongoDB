# 🍓 Fruits Database Application 🥝

A visually stunning web application that allows users to add and manage fruit names in a MongoDB database.

## ✨ Features

- 🎨 Beautiful, responsive UI built with React
- 🗄️ MongoDB database integration
- ➕ Add fruits to the database with a simple form
- 🗑️ Remove fruits from the database
- 📱 Mobile-friendly design with smooth animations

## 🚀 Setup Instructions

### Quick Setup

Run the included [install.bat](install.bat) file to install all dependencies automatically.

### Manual Setup

#### Backend Setup

1. Navigate to the backend directory: `cd backend`
2. Install dependencies: `npm install`
3. Create a `.env` file with your MongoDB connection string
4. Start the server: `npm start` or `npm run dev` for development

#### Frontend Setup

1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Access the application at http://localhost:3000

## 🛠️ Technologies Used

- ⚛️ React.js
- 📡 Node.js & Express.js
- 🍃 MongoDB & Mongoose
- 🎭 CSS for styling and animations
- 📦 Axios for API requests

## 📝 API Endpoints

- `GET /api/fruits` - Retrieve all fruits
- `POST /api/fruits` - Add a new fruit
- `DELETE /api/fruits/:id` - Remove a fruit by ID
